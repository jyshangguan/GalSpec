Every technical word used on these pages, in the order you are likely to meet it. Terms are explained for a reader who knows what a spectrum is but not what a "live point" or "dlogz" means.

Spectrum
Light split up by wavelength. The horizontal axis is wavelength, the vertical axis is how much light arrives at each wavelength. A spectrum tells you which atoms and which physical conditions produced the light.
Wavelength
The distance between two crests of a light wave, measured in Ångström (1 Å = 10-10 m). Visible light spans roughly 4000–7000 Å.
Flux
The amount of light energy arriving per unit area per unit time per unit wavelength. In these pages it is in the FITS file's own arbitrary units, so only relative values matter.
Pixel
One wavelength bin of the spectrum. This spectrum has one pixel every 0.046 Å.
Redshift (z)
Because the universe expands, light from a distant galaxy arrives stretched to longer wavelengths by a factor (1 + z). For IRAS 07546+3928, z = 0.0953, so every wavelength is 9.5% longer than in the galaxy's own frame.
Rest frame
Wavelengths as they would be measured by an observer sitting next to the galaxy, i.e. after dividing out the redshift. All plots here are in the rest frame, so the lines appear at their laboratory wavelengths.
Dereddening
Correcting for dust absorption by our own Milky Way, which both dims and reddens extragalactic light. We apply the standard Cardelli, Clayton & Mathis (1989) law with E(B−V) = 0.176.
Continuum
The smooth part of the spectrum, without the sharp lines. Here it is modelled as a power law: brightness proportional to wavelength−α.
Emission line
A sharp spike of extra light at one specific wavelength, produced when an electron drops to a lower energy level in an atom. Each element has its own set of wavelengths, which is how we know what the gas is made of.
Forbidden line
An emission line from a transition that is so slow that, in a laboratory, the atom is disturbed before it can emit. In the extremely thin gas of space it happens anyway. Written with square brackets, like [O III].
Narrow line
Light from gas moving slowly (a few hundred km/s), far from the black hole — the narrow-line region, hundreds to thousands of light years across.
Broad line
Light from gas whirling rapidly (thousands of km/s) around the black hole, within a few light years. Fast motion smears the line out in wavelength (the Doppler effect).
Gaussian
The bell curve, described by a peak height, a centre and a width σ. A line profile is modelled as a sum of a few Gaussians.
σ (sigma)
Two meanings, both standard. (1) The width of a Gaussian, in km/s. (2) The measurement error of a data point; residuals are quoted 'in σ', so +2 means 'two error bars above the model'.
FWHM
Full Width at Half Maximum: the width of a line measured at half its peak height. For a Gaussian, FWHM = 2.355 σ. Astronomers quote it because it can be read off a plot directly.
Line-spread function (LSF)
The profile a spectrograph imposes on an infinitely sharp line: a real instrument smears every line into a small bell curve. Ignoring it makes a fit try to explain instrumental smearing with the gas's own motion.
Resolving power (R)
R = wavelength / smallest resolvable wavelength difference. SDSS has R ≈ 2000, so at 5000 Å it can just separate features 2.5 Å apart.
Convolution
The mathematical operation of smearing one function with another: take the model, spread every point of it into the instrument's profile, and add up. Written f ∗ g.
Fe II (iron) emission
Thousands of blended emission lines from singly ionised iron. Together they look like a bumpy extra continuum, strongest bluewards of Hβ, and are modelled with a template spectrum scaled and blurred by the fit.
Tie (tied parameter)
A rule that forces one parameter to equal a function of others, e.g. 'all narrow lines share the width of [O III]'. Ties encode physics and remove parameters the data cannot constrain independently.
Prior
What you allow a parameter to be before looking at the data: a range (and a shape, e.g. uniform or log-uniform). Wide priors mean the answer comes from the data.
Posterior
The probability distribution of the parameters after the data are taken into account. It answers 'given this spectrum, which parameter values are plausible, and how precisely?'.
Likelihood
How probable the observed data are for a given set of parameters. For Gaussian errors it is exp(−χ²/2), so maximising the likelihood means minimising χ².
χ² (chi-squared)
The sum over all pixels of ((data − model) / error)². It is the natural measure of misfit when errors are Gaussian: 1 per pixel means a typical deviation of one error bar.
Degrees of freedom
The number of data points minus the number of fitted parameters. Dividing χ² by it gives the 'reduced χ²', which is ~1 for a good fit regardless of how many pixels there are.
Nested sampling
A way of mapping the posterior and computing the evidence at the same time: keep a set of 'live points' spread over the prior, repeatedly discard the worst one and replace it with a better one, so the live set shrinks onto the high-likelihood region. It handles awkward, multi-peaked posteriors that gradient methods miss.
Live points (nlive)
The number of parameter sets carried simultaneously by nested sampling. More live points means a more reliable map of the posterior, at proportionally higher cost.
log Z (log evidence)
The integral of likelihood × prior over all parameters, i.e. the average likelihood the model achieves over the whole prior. It is the number to compare models with, and the by-product of nested sampling.
dlogz (stopping threshold)
The estimated amount of evidence still unaccounted for when the sampler stops. Requiring dlogz < 0.01 means 'less than 1% of the evidence may still be missing', which forces the sampler to run until the answer is stable.
Sampler
The algorithm that explores the posterior. Here: dynesty (CPU, the existing code) and JNesty (GPU-capable, the new code).
jit (just-in-time compilation)
Turning a Python function into machine code the first time it is called. The compile cost is paid once; every later call is fast. That is why compiled timings here exclude the first call.
vmap (vectorised map)
Telling JAX to run a function on many inputs at once, laid out as an array. On a GPU this fills the device with work instead of evaluating points one by one.
JAX
A numerical library that compiles array code (like NumPy) for CPUs or GPUs. The GPU model in GalSpec is written in JAX so the same code runs on either device.
float64 / float32
How many bits a computer uses for a real number. float64 (~16 digits) is the default here, because likelihood values differ in the 10th digit; float32 is twice as fast on some GPUs but only accurate to ~7 digits, which we offer as an option (GALSPEC_JAX_X64=0) rather than the default.
GPU (graphics processing unit)
A chip with thousands of simple cores. Bad at sequential logic, excellent at doing the same arithmetic to a million numbers at once — which is what evaluating a model on a 59 146-pixel spectrum is.
Corner plot
A grid of histograms: the diagonal shows each parameter's posterior, the off-diagonal panels show pairs, revealing correlations. A compact way to see a 23-dimensional result.
Credible interval
The range containing a given probability (here 68%, i.e. 1σ) under the posterior. The Bayesian counterpart of a confidence interval.
